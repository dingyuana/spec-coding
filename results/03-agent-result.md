## 📄 我们写出来的文件

打开 `user-login/AGENT.md`，它是一份"编码公约"。不仅规定了代码风格，还规定了**什么不能做**。

### 4 条核心"禁止令"

| 禁止 | 为什么 |
|------|--------|
| ❌ 密码存明文 | 数据库泄露 = 所有用户密码裸奔 |
| ❌ JWT 密钥写死在代码里 | 代码上传 Git = 密钥全世界可见 |
| ❌ catch 后什么都不做 | Bug 静默消失，你不知道它出了错 |
| ❌ 登录错误区分"用户不存在"和"密码错误" | 黑客可以枚举出哪些用户存在 |

### 分层规范（代码必须按层放）

```
routes/          → 只写"哪个 URL 对应哪个函数"
controllers/     → 只写"参数校验 + 调用 service"
services/        → 只写"业务逻辑"
models/          → 只写"数据存取"
utils/           → 只写"工具函数"
```

> **禁止逆流：** controller 不能直接查数据库，service 不能返回 HTTP 响应。

### AGENT 和测试的关系

每一条 AGENT 的规则，最终都有一条测试来守护：

```
AGENT 说：密码不能明文存储 → 测试检查密码是否是 bcrypt 哈希
AGENT 说：登录不能泄露用户 → 测试检查错误消息是否一致
AGENT 说：参数缺失要报 400 → 测试只发一半参数，检查是否 400
```

> **没有测试守护的 AGENT，只是一张没人看的便利贴。**
