## 风格说明

所有插图统一使用以下三要素：

| 维度 | 设定值 |
|------|--------|
| **Type** | 按内容选择（flowchart / comparison / infographic / framework / timeline） |
| **Style** | `tech-blue` — 深蓝背景 + 青色/蓝色渐变线条 + 发光节点 + 简洁几何图形 |
| **Palette** | `blue-tech` — `#0a1628` (深蓝底) / `#1a3a6a` (中蓝) / `#3b82f6` (主蓝) / `#60a5fa` (亮蓝) / `#22d3ee` (青色高亮) |
