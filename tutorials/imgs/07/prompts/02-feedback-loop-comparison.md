# 反馈循环对比

## ZONES (2 columns)

Left column — **长循环 (写完全部再测)**
- Timeline: "写 2 小时" → "跑 1 分钟" → "11 个失败" → "定位 30 分钟" → "改" → "又 3 个新失败"
- Lengthy winding path
- Red warning markers at each failure
- Total time: "整个下午"

Right column — **短循环 (每次改一个文件)**
- Compact loops: "改 2 分钟" → "跑 1 秒" → "绿色 ✅" → (repeat 5 times)
- Short straight path
- Green checkmark after each step
- Total time: "半小时"
